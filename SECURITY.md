# Security and deployment scope

This repository contains a hackathon prototype, not a production service or an
official TSA or GSA system. Run it locally via stdio or in an approved private
sandbox. Do not expose the prototype to the public internet. The optional HTTP
transport is not an authorization boundary.

Use only the included synthetic data and appropriately sourced public data.
Do not connect live agency systems or introduce restricted information, personal
data, access keys, private endpoints, or credentials. Keep environment settings
and authentication material local; do not attach them to issue reports or logs.

Report a suspected security problem privately to the repository maintainers
rather than opening a public issue with sensitive details. This policy does not
authorize testing any government, vendor, or third-party system.
